⚙️ Guide de configuration

Suis ces étapes une seule fois pour connecter le formulaire à ton Google Sheets :

1
Va sur sheets.google.com et crée un nouveau tableau intitulé "Tontine".
2
Dans le menu, clique sur Extensions → Apps Script.
3
Supprime tout le code existant et colle le contenu du fichier google_apps_script.gs fourni avec ce formulaire.
4
Clique sur Déployer → Nouveau déploiement. Choisis "Application Web". Dans "Qui a accès", sélectionne "Tout le monde". Clique sur Déployer.
5
Copie l'URL de déploiement (commence par https://script.google.com/macros/s/...) et colle-la dans le champ en haut de ce formulaire.
💡 Astuce : Partage ensuite le lien de ce fichier HTML via WhatsApp à chaque membre. Ils remplissent le formulaire et les données arrivent automatiquement dans ton Google Sheets !
